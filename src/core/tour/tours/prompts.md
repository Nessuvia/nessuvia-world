# Prompts

## center
A prompt stack is the order the parts of a prompt are assembled in: the system text, the character,
the persona, the lorebook entries and the history.

## .zones
Blocks run top to bottom. Drag one to move it, and a chat sends whatever this order produces.

## .blockList
Each block is one piece of the prompt. Click it to edit its text or turn it off.

## .stackBudget
The token budget. History is trimmed from the oldest end when the total goes over it.

## .presetRow
Stacks are saved as presets. A chat picks one in its rail.
