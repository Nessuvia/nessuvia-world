What it does

Chat
Talk with character cards. Import cards you already have, or make your own.
Write
Longer-form stories in chapters, with the same characters and world info.
Multiplayer
Guests join your chat from a link. Turn order and a narrator are built in.
Ask
A scratchpad for one-off questions to the model.

Where your data goes

Characters, chats and stories are stored in your browser. There are no accounts and no server of ours holds your data. Three things leave the tab:

  • The model endpoint you configure, using your own API key.
  • The multiplayer relay, when you host or join a session. Nothing is stored there.
  • Your own S3-compatible bucket, if you turn on sync.

Requirements

A modern browser and an API key for an OpenAI-compatible model endpoint, hosted or running on your own machine. The app installs as a PWA.
