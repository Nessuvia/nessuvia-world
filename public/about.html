What it does

Chat
Existing character cards import, or write a new one here.
Write
Stories run long here, in chapters, using the same characters and world info.
Multiplayer
Direct people to a link and they land in your chat. Everyone gets a turn, and a narrator fills the gaps.
Ask
Single questions go straight to the model, outside any chat.

Models and settings

Local or hosted models
Reach any OpenAI-compatible endpoint, hosted or running on your own machine. Text completion and chat completion both work.
Modular samplers
One sampler parameter is one row of data, not code. That means a sampler your backend supports but Xenia has never heard of is one you can add, and it appears in the UI.
Import and export
One JSON file holds everything, and it imports on the next machine. API keys and bucket credentials are blanked before the file is written.

Where your data goes

All of it sits in your browser: characters, chats, stories, settings. There is no account to make and no server of ours to hold any of it. Outside the tab, three things travel:

  • Generated replies come from the model endpoint you configure, with your own API key.
  • Others in a multiplayer session reach you through a relay that stores nothing.
  • Turning on sync writes your records to your own S3-compatible bucket.

Requirements

A modern browser, and an API key for an OpenAI-compatible endpoint, hosted or on your own machine. Once loaded, the app installs as a PWA.

Status

Zero cost to use. The developer behind it uses it daily, and new features land often.
